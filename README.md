# VoxCraft — Text to Voice Converter

Advanced, responsive browser text-to-speech studio.

## Features
- Web Speech API text-to-speech
- System voice and locale selection
- Speed, pitch, and volume controls
- Speak, pause/resume and stop
- Long-text chunking for reliable playback
- Character, word and duration counters
- Podcast, Natural, Presenter and Storyteller presets
- Dark/light theme with saved preference
- Keyboard shortcut: Ctrl/Cmd + Enter
- No API key or backend required

## Run
Open `index.html` in Chrome, Edge, or another modern browser with speech synthesis support.

## Deploy
Works as a static site on GitHub Pages, Vercel, Netlify, or similar hosts.
